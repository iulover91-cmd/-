═══════════════════════════════════════════════════════
  프리랜서 관리 시스템 (FMS) - 시작 가이드
═══════════════════════════════════════════════════════

▶ 1단계: Node.js 설치 (한번만 하면 됩니다)
───────────────────────────────────────────
  1. 브라우저에서 https://nodejs.org 접속
  2. "LTS" 버전 다운로드 (큰 초록색 버튼)
  3. 다운받은 파일 실행 → "Next" 계속 클릭하여 설치
  4. 설치 완료!


▶ 2단계: 프로그램 설치 (한번만 하면 됩니다)
───────────────────────────────────────────
  1. 바탕화면의 "pre" 폴더를 탐색기에서 엽니다
  2. 탐색기 주소창에 "cmd" 입력 후 Enter
     (또는 Shift + 우클릭 → "여기에서 명령 프롬프트 열기")
  3. 아래 명령어를 복사해서 붙여넣기 후 Enter:

     npm install

  4. 설치가 완료될 때까지 기다립니다 (1~2분)


▶ 3단계: 프로그램 실행
───────────────────────────────────────────
  같은 명령 프롬프트 창에서:

     npm start

  아래 메시지가 나오면 성공입니다:
  ========================================
    프리랜서 관리 시스템 시작!
    로컬: http://localhost:3000
  ========================================


▶ 4단계: 접속하기
───────────────────────────────────────────
  브라우저에서 http://localhost:3000 접속

  관리자 로그인 정보:
    아이디: admin
    비밀번호: admin1234


▶ 5단계: 프리랜서 등록하기
───────────────────────────────────────────
  1. 관리자로 로그인
  2. 왼쪽 메뉴 "프리랜서 관리" 클릭
  3. "프리랜서 추가" 버튼 클릭
  4. 이름, 단가, 구글 드라이브 폴더 URL 입력 후 저장

  → 프리랜서가 추가되면 자동으로 로그인 아이디가 생성됩니다
  → 비밀번호 초기값은 1234 (프리랜서가 직접 변경 가능)


═══════════════════════════════════════════════════════
  외부 접속 설정 (노트북/프리랜서가 밖에서 접속)
═══════════════════════════════════════════════════════

방법 1: ngrok 사용 (가장 쉬움, 무료)
─────────────────────────────────────
  1. https://ngrok.com 에서 회원가입 (무료)
  2. ngrok 다운로드 및 설치
  3. 명령 프롬프트에서:

     ngrok http 3000

  4. 화면에 나오는 주소 (예: https://abc123.ngrok.io)를
     프리랜서들에게 공유하면 끝!

  ※ 무료 버전은 매번 주소가 바뀝니다
  ※ 유료 버전($8/월)을 쓰면 고정 주소 사용 가능


방법 2: 클라우드 서버 사용 (추천 - 24시간 운영)
───────────────────────────────────────────────
  저렴한 클라우드 서버 추천:
  - Vultr: 월 $6 (약 8,000원) / 가장 쉬움
  - DigitalOcean: 월 $4 (약 5,500원)
  - AWS Lightsail: 월 $3.5 (약 4,800원)

  설정 방법:
  1. 위 서비스 중 하나에 가입하여 Ubuntu 서버 생성
  2. 서버에 Node.js 설치
  3. 이 프로그램 폴더를 서버에 업로드
  4. npm install && npm start
  5. 서버 IP 주소로 접속 가능!


방법 3: 포트 포워딩 (무료, 약간 복잡)
────────────────────────────────────
  1. 공유기 설정 페이지 접속 (보통 192.168.0.1)
  2. 포트 포워딩 설정에서 3000번 포트를 PC의 내부 IP로 연결
  3. 외부에서 "내_공인IP:3000" 으로 접속
  ※ 보안에 주의가 필요합니다


═══════════════════════════════════════════════════════
  Google Drive 자동 연동 설정 (선택사항)
═══════════════════════════════════════════════════════

  ※ 이 설정은 나중에 해도 됩니다!
  ※ 설정하지 않아도 수동으로 파일을 등록할 수 있습니다

  1. https://console.cloud.google.com 접속
  2. 새 프로젝트 생성
  3. "API 및 서비스" → "라이브러리" → "Google Drive API" 활성화
  4. "사용자 인증 정보" → "서비스 계정 만들기"
  5. 만들어진 서비스 계정 → "키" 탭 → JSON 키 생성 → 다운로드
  6. 다운로드한 JSON 파일을 열어서:
     - client_email 값을 복사
     - private_key 값을 복사
  7. pre 폴더의 .env 파일을 메모장으로 열어서:
     GOOGLE_CLIENT_EMAIL=복사한_이메일
     GOOGLE_PRIVATE_KEY="복사한_키"
  8. 각 프리랜서의 구글 드라이브 폴더에
     서비스 계정 이메일(client_email)을 "뷰어"로 공유 추가
  9. 서버를 재시작하면 5분마다 자동 체크!


═══════════════════════════════════════════════════════
  자주 묻는 질문
═══════════════════════════════════════════════════════

Q: 프로그램을 종료했다가 다시 시작하면 데이터가 사라지나요?
A: 아닙니다! 데이터는 freelancer.db 파일에 저장되어 영구 보존됩니다.

Q: 프리랜서가 늘어나면 코드를 수정해야 하나요?
A: 아닙니다! 관리자 화면에서 "프리랜서 추가" 버튼만 누르면 됩니다.

Q: 단가가 바뀌면 어떻게 하나요?
A: 프리랜서 관리 → 해당 프리랜서 "수정" 버튼 → 단가 변경 → 저장

Q: 비밀번호를 잊어버리면?
A: 관리자가 "PW초기화" 버튼으로 새 비밀번호를 설정해줄 수 있습니다.

Q: 서버를 끄면 외부에서 접속이 안 되나요?
A: 네. 24시간 접속이 필요하면 클라우드 서버를 사용하세요.
